검진 결과 일괄 입력

값을 입력한 항목만 저장합니다. 그 날짜에 이미 있는 기록은 미리 채워지며, 값을 지워도 기록은 삭제되지 않습니다. 항목별 비고를 비워 두면 공통 비고가 저장됩니다.

사용자 추가

성별

검진 항목 추가

같은 이름의 항목은 대상 성별이 '전체'면 하나만, 남/여로 나누면 성별당 하나씩 만들 수 있습니다.

판정 구간

정상 구간은 필수입니다. 경계·위험 등은 필요에 따라 추가하세요. 최소/최대 중 한쪽만 입력하면 열린 구간(이상/이하)이 됩니다.

문자열 항목은 판정 구간 없이 기록만 관리합니다. (예: 요잠혈의 음성/양성)

카테고리 관리

카테고리를 삭제해도 항목은 삭제되지 않고 '미분류'가 됩니다.

아직 카테고리가 없습니다.

순서 편집

카테고리는 소속 항목과 함께 움직입니다. 항목은 같은 카테고리 안에서만 움직이며, 카테고리를 바꾸려면 항목 수정에서 하세요.

항목 합치기

합칠 항목의 모든 사용자 기록을 남길 항목으로 옮기고, 합칠 항목은 삭제합니다. 단위·판정 구간·카테고리는 남길 항목 것을 씁니다.

값 유형이 같은 다른 항목이 없습니다.

CSV 내보내기

가져오기와 같은 형식이라 내려받은 파일을 그대로 다시 가져올 수 있습니다. 항목은 표시 순서대로 나옵니다. 엑셀에서 바로 열립니다.

CSV 가져오기

파일 전체를 먼저 검증하고, 오류가 하나라도 있으면 아무것도 저장하지 않습니다. 이름이 같은 것은 덮어씁니다. UTF-8과 CP949(엑셀 기본) 모두 읽습니다.
