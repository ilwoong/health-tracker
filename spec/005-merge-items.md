# 005. 검진 항목 합치기

- 상태: 구현됨
- 작성일: 2026-10-06
- 기준 문서: [design.md](design.md), [001](001-item-category.md)

## 목적

같은 검사가 다른 이름으로 두 번 만들어지는 일이 생긴다(예: `LDL 콜레스테롤`과 `저밀도 콜레스테롤`).
한쪽의 기록을 다른 쪽으로 옮기고 한쪽을 없애 하나로 합친다.

## 결정 사항

| 항목 | 결정 |
| --- | --- |
| 방향 | **남길 항목**과 **합칠 항목**을 정한다. 합칠 항목의 모든 사용자 기록을 남길 항목으로 옮기고, 합칠 항목은 삭제한다 |
| 남는 속성 | 이름·단위·판정 구간·카테고리·표시 순서·대상 성별은 모두 남길 항목 것. 합칠 항목의 구간은 버린다 |
| 같은 날짜 충돌 | 같은 사용자·같은 날짜 기록이 양쪽에 있으면 **남길 항목 값을 유지**하고 합칠 항목 쪽은 버린다. 미리보기에 건수를 표시한다 |
| 값 유형 | 숫자/문자가 같은 항목끼리만 합칠 수 있다 |
| 대상 성별 | 남길 항목의 대상 성별에 맞지 않는 사용자의 기록이 합칠 항목에 있으면 **중단**한다 (기록이 가려지는 것을 막음). 남길 항목의 성별을 '전체'로 바꾼 뒤 다시 하면 된다 |
| 진입점 | 남길 항목의 상세 화면 → `합치기` 버튼 |
| 되돌리기 | 없음. 미리보기와 확인으로 대신한다 |

## 기능 요구사항

### 합치기 모달 (항목 상세 화면)
- 상세 화면 헤더에 `수정` · `합치기` · `삭제` 순으로 버튼을 둔다.
- 모달에는 남길 항목(현재 항목) 이름과, 합칠 항목을 고르는 선택창이 있다.
  - 선택창에는 값 유형이 같은 다른 항목 전부를 보여 준다. 로그인 사용자 성별로 숨겨진 항목도 포함한다(항목은 공유이므로).
    성별 전용 항목은 성별 태그를 붙인다.
  - 후보가 없으면 안내 문구를 보여 주고 `합치기` 버튼을 비활성화한다.
- 합칠 항목을 고르면 서버에서 **미리보기**를 받아 표시한다.
  - 옮겨질 기록 수와 사용자 수
  - 같은 날짜 충돌 수 (→ 버려짐)
  - 경고: 단위가 다름, 합칠 항목의 판정 구간이 버려짐
  - 중단 사유(있으면): 성별 때문에 가려질 사용자 이름. 이때 `합치기` 버튼은 비활성
  - 마지막 줄에 "'합칠 항목' 항목은 삭제됩니다"
- `합치기`를 누르면 실행하고 모달을 닫은 뒤 현재 상세 화면을 갱신한다(기록 표·그래프에 옮겨온 기록이 보임).

## API

### 미리보기 (신규)
- `GET /api/items/{keep_id}/merge-preview?from={from_id}`
  - 응답: `{moved, dropped, users, warnings: [str], blocked: [str]}`
    - `moved`: 옮겨질 기록 수(충돌 제외), `dropped`: 충돌로 버려질 수, `users`: 합칠 항목에 기록이 있는 사용자 수
    - `blocked`가 비어 있지 않으면 합칠 수 없다
  - 두 id가 같거나 값 유형이 다르면 422, 없는 항목이면 404

### 실행 (신규)
- `POST /api/items/{keep_id}/merge` — body `{from_id}`
  - 미리보기와 같은 검사를 다시 하고, `blocked`가 있으면 422
  - 한 트랜잭션으로: 충돌 기록 삭제 → 나머지 기록의 item_id를 keep으로 변경 → 합칠 항목 삭제
    (항목을 먼저 지우면 CASCADE로 기록이 함께 지워지므로 순서가 중요하다)
  - 응답: `{moved, dropped}`

## 범위 밖

- 되돌리기(언두)
- 세 개 이상 한 번에 합치기 (두 개씩 반복하면 된다)
- 값 단위 환산 (단위가 다르면 경고만 하고 값은 그대로 옮긴다)
