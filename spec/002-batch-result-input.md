# 002. 검진 결과 일괄 입력

- 상태: 구현됨 (`fca5baa`)
- 작성일: 2026-10-06
- 기준 문서: [design.md](design.md)

## 목적

지금은 항목 상세 화면에서 항목 하나씩 날짜와 값을 입력한다.
종합검진처럼 같은 날짜에 여러 항목을 입력해야 할 때는 항목마다 화면을 오가야 해서 불편하다.
한 화면에서 날짜 하나를 정하고 등록된 검진 항목들의 값을 한 번에 입력한다.

## 결정 사항

| 항목 | 결정 |
| --- | --- |
| 화면 | 별도 화면(view). 대시보드 헤더의 `일괄 입력` 버튼으로 진입 |
| 대상 항목 | 로그인 사용자의 성별에 맞는 항목 전체 (대시보드와 동일), 항목 이름순 |
| 기존 값 | 선택한 날짜에 이미 기록된 값을 입력칸에 미리 채움 |
| 비고 | 공통 비고 + 항목별 비고. 항목별 비고가 있으면 그것을, 없으면 공통 비고를 저장 |
| 저장 | 한 번의 요청으로 저장하고, 하나라도 실패하면 아무것도 저장하지 않음 |
| 카테고리 | 001 구현 전이므로 이름순 목록. 카테고리별 묶음은 [001의 일괄 입력 화면 절](001-item-category.md#일괄-입력-화면-002)에서 정의 |

## 기능 요구사항

### 화면 구성
- 상단: 날짜(기본값 오늘), 공통 비고
- 항목 목록: 항목마다 한 줄
  - 항목 이름(+ 성별 전용 항목 표시), 값 입력칸, 단위, 판정 배지, 항목별 비고 입력칸
  - 숫자형 항목은 숫자 입력칸, 문자형 항목은 문자열 입력칸
  - 숫자형 항목은 값을 입력하는 즉시 판정 배지를 표시한다.
- 하단: `취소`, `N개 항목 저장` 버튼 (저장할 항목이 없으면 비활성)
- 등록된 항목이 없으면 안내 문구를 표시한다.

### 기존 값 미리 채우기
- 날짜를 정하면 그 날짜에 기록된 값과 비고를 해당 항목 줄에 채운다.
- 미리 채운 줄은 값이나 항목별 비고를 바꿨을 때만 저장 대상이 된다.
  공통 비고만 바꾼 경우에는 기존 기록을 다시 저장하지 않는다.
- 미리 채운 값을 지워도 기존 기록은 삭제되지 않는다. 삭제는 상세 화면에서 한다.

### 저장 대상
- 값이 입력된 줄 중에서
  - 그 날짜에 기존 기록이 없는 줄, 또는
  - 기존 기록과 값 또는 항목별 비고가 다른 줄
- 저장되는 비고: 항목별 비고가 있으면 항목별 비고, 비어 있으면 공통 비고
- 같은 날짜에 기록이 있으면 덮어쓴다 (기존 단건 입력과 동일한 규칙).

### 입력 편의
- 값 입력칸에서 Enter를 누르면 저장하지 않고 다음 항목의 값 입력칸으로 이동한다.
- 입력 중인 값이 있는 상태에서 날짜를 바꾸거나 화면을 나가면 확인 창을 띄운다.
  - 날짜 변경을 취소하면 이전 날짜로 되돌린다.
- 저장이 끝나면 대시보드로 돌아가 최근 결과를 갱신한다.

## API

### 날짜별 결과 조회 (신규)
- `GET /api/users/{uid}/results?date=YYYY-MM-DD`
  - 해당 사용자가 그 날짜에 기록한 모든 항목의 결과 목록
  - 날짜 형식이 잘못되면 422

### 일괄 저장 (신규)
- `POST /api/users/{uid}/results/batch`
  - body: `{date, entries: [{item_id, value | value_text, note}]}`
  - 각 entry는 단건 입력(`POST /api/users/{uid}/items/{iid}/results`)과 같은 규칙으로 검증하고 upsert한다.
  - entries가 비어 있거나 같은 item_id가 중복되면 422, 존재하지 않는 item_id가 있으면 404
  - 하나라도 실패하면 전체를 저장하지 않는다 (트랜잭션 하나로 처리).
  - 응답: 저장된 결과 목록

비고 결정(공통/항목별)은 프론트엔드에서 처리해 entry마다 최종 비고를 보낸다.

## 범위 밖

- 일괄 입력 화면에서 기존 기록 삭제
- 항목 검색/필터 (001에서 필터 칩 없이 섹션 제목만 붙이기로 결정)
- 여러 날짜 동시 입력
- 새로고침·탭 닫기 시 입력값 보호 (확인 창은 `목록`/`취소` 버튼으로 나갈 때만 표시)
