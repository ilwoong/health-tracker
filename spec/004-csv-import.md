# 004. CSV 가져오기

- 상태: 구현됨 (`fd1d46d`)
- 작성일: 2026-10-06
- 기준 문서: [design.md](design.md), [001](001-item-category.md), [002](002-batch-result-input.md)

## 목적

처음 설정할 때 카테고리·검진 항목을 수십 개 만들거나, 과거 검진 결과를 여러 해치 한꺼번에 넣을 때
화면에서 하나씩 입력하는 것은 느리다. 엑셀에서 정리한 CSV 파일을 올려 한 번에 넣는다.

## 결정 사항

| 항목 | 결정 |
| --- | --- |
| 대상 | 카테고리, 검진 항목(판정 구간 포함), 검진 결과(로그인 사용자) 세 종류 |
| 중복 | 덮어쓰기. 카테고리는 이름, 항목은 이름+대상 성별, 결과는 항목+날짜 기준 |
| 항목의 카테고리 | 없는 이름이면 자동 생성 |
| 실패 규칙 | 파일 전체를 먼저 검증하고, 오류가 하나라도 있으면 아무것도 저장하지 않음 (002와 동일) |
| 진입점 | `설정 ▾` → `CSV 가져오기` 모달 |
| 인코딩 | UTF-8(BOM 유무 무관) 우선, 실패 시 CP949(EUC-KR). Windows 엑셀 기본 저장을 그대로 받기 위함 |
| 의존성 | 추가하지 않음. 브라우저가 파일을 텍스트로 읽어 JSON으로 보내고, 서버는 표준 `csv` 모듈로 파싱 |

## 파일 형식

첫 줄은 헤더. 열 순서는 상관없고, 모르는 열은 무시한다. 값은 앞뒤 공백을 제거한다.

### 카테고리 `categories.csv`
| 열 | 필수 | 설명 |
| --- | --- | --- |
| name | O | 카테고리 이름. 규칙은 001과 동일(빈 값·'미분류' 불가) |

### 검진 항목 `items.csv` — 판정 구간 하나당 한 줄
| 열 | 필수 | 설명 |
| --- | --- | --- |
| item_name | O | 항목 이름 |
| category | | 카테고리 이름. 비우면 미분류. 없는 이름이면 자동 생성 |
| unit | | 단위 |
| value_type | | `NUMBER`(기본) / `TEXT` |
| target_gender | | `ALL`(기본) / `M` / `F` |
| judgement_level | NUMBER면 O | 판정 수준 이름 |
| min_value, max_value | | 구간 경계. 둘 중 하나는 필수 |
| color | | `ok`/`lowish`/`warn`/`danger`/`etc`. 비우면 UI와 같은 키워드 규칙으로 제안 |

- 같은 (item_name, target_gender) 줄들이 한 항목이 되고, 줄 순서대로 구간이 된다.
  category/unit/value_type은 첫 줄 값을 쓰며, 뒤 줄이 다르면 오류.
- TEXT 항목은 한 줄만 쓰고 구간 열은 비운다. 구간이 있으면 오류.
- 기존 항목을 덮어쓸 때는 PUT과 같이 구간 전체를 교체한다. 결과가 있는 항목의 value_type 변경은 오류.
- 같은 이름 규칙(ALL과 M/F 공존 불가)은 001과 동일하게 검사한다.

### 검진 결과 `results.csv` — 로그인한 사용자의 결과
| 열 | 필수 | 설명 |
| --- | --- | --- |
| date | O | YYYY-MM-DD |
| item_name | O | 로그인 사용자 성별에 보이는 항목 중에서 이름으로 찾음. 없으면 오류 |
| value | O | 숫자형이면 숫자, 문자형이면 문자열 |
| note | | 비고 |

- 같은 (item_name, date)가 파일 안에 두 번 있으면 오류.

## 동작

1. 모달에서 종류 선택 → `양식 다운로드`로 헤더와 예시 한 줄이 든 CSV(UTF-8 BOM)를 받을 수 있다.
2. 파일 선택 → `가져오기`.
3. 서버가 전체를 검증한다. 오류는 `3행: 'AST' 항목의 min_value가 숫자가 아닙니다`처럼 **행 번호와 함께 전부** 모아서 돌려준다.
4. 오류가 없으면 한 트랜잭션으로 저장하고 결과를 표시한다: 예) `카테고리 2건 추가 · 항목 10건 추가, 2건 갱신`.
5. 저장 후 대시보드를 갱신한다.

## API

- `POST /api/import/categories` — body `{csv}` → `{created, updated}`
- `POST /api/import/items` — body `{csv}` → `{created, updated, categories_created}`
- `POST /api/users/{uid}/import/results` — body `{csv}` → `{created, updated}`
- 검증 오류: 422, `detail`은 오류 메시지 문자열 배열
- 헤더에 필수 열이 없거나 데이터 줄이 없으면 422

## 범위 밖

- CSV 내보내기 (백업 용도로는 `data/health.db` 복사)
- 파일 안의 행 순서를 표시 순서(003)로 저장
- 여러 사용자의 결과를 한 파일로 가져오기 (파일에 user 열 추가로 확장 가능)
- 엑셀(.xlsx) 직접 읽기
