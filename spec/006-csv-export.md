# 006. CSV 내보내기

- 상태: 구현됨
- 작성일: 2026-10-06
- 기준 문서: [004](004-csv-import.md)

## 목적

항목 정의와 검진 결과를 엑셀에서 보거나 다른 곳에 옮기고, 다시 가져올 수 있게 CSV로 내려받는다.
가져오기(004)와 같은 형식이라 **내보낸 파일을 그대로 다시 가져올 수 있다.**

## 결정 사항

| 항목 | 결정 |
| --- | --- |
| 종류 | 카테고리 / 검진 항목(판정 구간 포함) / 검진 결과(로그인 사용자) — 가져오기와 동일한 세 종류 |
| 형식 | 004의 열 구성과 동일. UTF-8 BOM(엑셀에서 바로 열림) |
| 순서 | 항목·카테고리는 표시 순서(003), 결과는 항목 표시 순서 → 날짜 오름차순 |
| 진입점 | `설정 ▾` → `CSV 내보내기` 모달에서 종류를 고르고 다운로드 |
| 파일 이름 | `categories.csv`, `items.csv`, `results_<사용자>_<오늘>.csv` |

## 동작

- 모달에서 종류를 고르고 `다운로드`를 누르면 브라우저가 파일을 저장한다.
- 항목 내보내기는 항목이 표시 순서대로 나오므로, 그대로 가져오기(행 순서 저장 옵션)하면 순서가 유지된다.
- 결과 내보내기는 로그인한 사용자의 모든 기록이다. 다른 가족은 그 사용자로 로그인해 내보낸다.
- 데이터가 없으면 헤더만 있는 파일을 내려준다.

## API

- `GET /api/export/categories.csv`
- `GET /api/export/items.csv`
- `GET /api/users/{uid}/export/results.csv`
- 응답: `text/csv; charset=utf-8`, BOM 포함, `Content-Disposition: attachment`

## 범위 밖

- 전체 백업(모든 사용자 결과 한 파일) — `data/health.db` 복사로 대신
- 엑셀(.xlsx) 직접 생성
